# package:osqp

This Dart package is a wrapper around [OSQP](https://github.com/osqp/OSQP), a
fast quadratic programming solver. Quadratic programming is a powerful tool for
numerical optimisation. QP is a superset of linear programming, so this solver
can also handle linear programming problems. See the
[OSQP documentation](https://osqp.org/) for more info.
